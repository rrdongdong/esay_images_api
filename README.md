## 简介

Easy Images API 是一个纯前端的图像生成工具：填入 API 密钥和主机地址，就能直接调用图像生成接口，并自动等待异步任务返回结果。

- **零依赖**：没有 npm、没有构建步骤，浏览器打开即用
- **无后端**：所有请求由浏览器直接发出
- **密钥本地保存**：API 密钥只存在你自己浏览器的 `localStorage` 里，不会上传到任何第三方服务器

## 在线使用

直接访问：**https://rrdongdong.github.io/esay_images_api/**

若链接无法打开，请到仓库 **Settings → Pages** 确认已开启，Source 选择 `Deploy from a branch` → `main` → `/ (root)`。

使用步骤：

1. 输入 **API 密钥**
2. 输入 **API 主机地址**（默认 `https://api.apib.ai`，需以 `http://` 或 `https://` 开头）
3. 点击「登录」，填写提示词，点击「✨ 生成图片」

## 本地使用

下载 [index.html](index.html) 后双击打开即可，无需安装任何环境。所有功能与线上版本一致。

## 功能

| 功能 | 说明 |
| --- | --- |
| 多模型 | Nano Banana 2、GPT-Image-2 |
| 画面比例 | 1:1、16:9、9:16、3:2、2:3、4:3、3:4、5:4、4:5、21:9 等 |
| 分辨率 | 0.5K / 1K / 2K / 4K（随模型不同） |
| 质量与数量 | 仅 GPT-Image-2 支持，单次最多 4 张 |
| 异步任务 | 提交后自动轮询任务状态，完成后展示图片 |
| 结果操作 | 下载、新窗口打开 |
| 快捷键 | `Ctrl + Enter`（macOS 为 `⌘ + Enter`）快速生成 |
| 状态记忆 | 主机地址与密钥保存在浏览器本地，下次打开免输入 |

## 调用的接口

工具按 OpenAI 风格的图像接口调用，均需在请求头中携带 `Authorization: Bearer <你的密钥>`：

| 用途 | 方法 | 路径 |
| --- | --- | --- |
| 提交生成任务 | `POST` | `/v1/images/generations` |
| 查询任务状态 | `GET` | `/v1/tasks/{task_id}` |

其中主机地址由你在登录页填写，因此可对接任何兼容该协议的图像生成服务。

## 注意事项

- **跨域限制（CORS）**：请求由浏览器直接发出，如果你的 API 服务未返回 `Access-Control-Allow-Origin`，浏览器会拦截请求并提示生成失败。彻底的解决办法是自建一层轻量代理（见待办事项 P0）。
- **密钥安全**：密钥以明文保存在 `localStorage`（键名 `img_gen_state`）。在公共电脑上使用后请点击「退出登录」；另外当前「设置」面板会明文回显密钥，待改造。
- **成本提示**：`high` 质量搭配 `4K` 分辨率花费高、耗时长，界面会二次确认；单次生成最长等待约 6 分钟。
- **下载限制**：目前跨域图片的「下载」按钮实际会打开新窗口，而非真正下载，待修复。
